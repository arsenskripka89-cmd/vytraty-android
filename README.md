# Витрати (Vytraty) — Android-менеджер витрат з автозахопленням платежів

Android-застосунок для обліку особистих фінансів. Головна відмінність від застосунків у Play Market:
**оплати з Google Pay та банківських застосунків записуються автоматично** зі сповіщень, без ручного вводу.

## Що вміє

- **Автозахоплення платежів зі сповіщень** — Google Pay / Google Wallet, Monobank, Приват24, Raiffeisen (MyRaif),
  Revolut, Ощадбанк, ПУМБ. Сума, валюта, магазин і останні 4 цифри картки витягуються з тексту сповіщення.
- **Позначки в історії** — операція зі сповіщення має іконку «дзвіночок», з банківського API — «банк»;
  показано, з якої картки списано (•••• 1234); операція без категорії підсвічена жовтим.
- **Навчання «магазин → категорія»** — після першого призначення категорії операції з магазином застосунок
  запам'ятовує пару і далі призначає категорію сам. Пропонує застосувати категорію до всіх старих
  операцій цього магазину. Правила можна переглянути й видалити.
- **Гаманці** — готівка, картки, рахунки; валюта, початковий баланс, колір; останні 4 цифри картки для
  зіставлення зі сповіщенням; гаманець за замовчуванням.
- **Категорії** витрат і доходів з іконкою та кольором (стартовий набір українською).
- **Ручний ввід** — витрата / дохід / переказ між гаманцями, дата, магазин, нотатка.
- **Історія** — по днях, фільтри за місяцем, гаманцем, категорією, «лише без категорії», пошук.
- **Аналітика** — кільцева діаграма за категоріями, стовпчики витрати/доходи за 6 місяців, лінія динаміки за місяць.
- **Планові платежі** — повторювані (тиждень/місяць/рік) або разові, нагадування за N днів зі сповіщенням
  та кнопкою «Записати платіж» прямо у сповіщенні.
- **Бюджети** — місячний ліміт на категорію або на всі витрати, сповіщення при 80 % та 100 %.
- **Monobank API** — імпорт рахунків як гаманців і виписки (31 день, далі щогодини) за персональним токеном.
- **Експорт CSV**, журнал захоплених сповіщень, тестер парсера (вставити текст сповіщення — побачити результат).

Приват24, Raiffeisen і Revolut не мають відкритого особистого API з простою авторизацією, тому підтримуються
лише через сповіщення. Для додавання інтеграції є інтерфейс `BankConnector`.

## Збірка

Потрібні JDK 17 та Android SDK (platform 35, build-tools 35). Локальна збірка на цій машині вже налаштована:
toolchain лежить у `C:\Users\admin\android-toolchain`, шлях до SDK — у `local.properties`.

```powershell
$env:JAVA_HOME = "C:\Users\admin\android-toolchain\jdk"
cd C:\Users\admin\ExpenseManager
.\gradlew.bat assembleDebug          # APK: app\build\outputs\apk\debug\app-debug.apk
.\gradlew.bat testDebugUnitTest      # юніт-тести парсерів та доменної логіки
```

Або відкрийте папку в Android Studio (Ladybug або новіша) і натисніть Run.

## Оновлення

Застосунок сам перевіряє нові версії раз на добу та при запуску (GitHub Releases репозиторію
`arsenskripka89-cmd/vytraty-android`) і показує сповіщення. Вручну: **Налаштування → Перевірити оновлення →
Завантажити та встановити**. Перший раз Android попросить дозволити цьому застосунку встановлювати невідомі програми.

Щоб випустити нову версію:

1. Підняти `versionCode` і `versionName` в `app/build.gradle.kts`.
2. `.\gradlew.bat assembleRelease` (підпис береться з `keystore.properties`, файл не в git).
3. `gh release create vX.Y.Z app\build\outputs\apk\release\app-release.apk --title "Витрати X.Y.Z" --notes "..."`.

Ключ підпису `keystore/vytraty-release.jks` та `keystore.properties` зберігайте в резервній копії:
без них не можна випустити оновлення, яке встановиться поверх наявної версії.

## Встановлення та перший запуск

1. Завантажте APK з останнього релізу на https://github.com/arsenskripka89-cmd/vytraty-android/releases
   і встановіть на телефон (увімкніть «Невідомі джерела»).
2. Відкрийте застосунок → на Огляді торкніться банера «Автозахоплення вимкнено» → у системних
   налаштуваннях увімкніть доступ до сповіщень для «Витрати».
3. У **Ще → Гаманці** вкажіть для кожної картки останні 4 цифри — так платежі потраплятимуть у правильний гаманець.
4. Увімкніть у банківському застосунку сповіщення про операції (push).
5. Зробіть оплату — операція з'явиться в історії з жовтою позначкою «Без категорії». Відкрийте її, оберіть
   категорію — наступного разу цей магазин отримає категорію автоматично.

Якщо сповіщення не розпізналось, воно є в **Ще → Журнал сповіщень**. Скопіюйте його текст у
**Налаштування → Тестер парсера** — це допоможе підібрати шаблон (парсери в
`app/src/main/java/ua/vytraty/app/domain/parser/PaymentParsing.kt`, тести — `app/src/test`).

## Архітектура

```
app/src/main/java/ua/vytraty/app/
  data/db/          Room: сутності, DAO, стартові дані
  data/prefs/       DataStore-налаштування
  data/bank/        BankConnector + Monobank API/синхронізація (WorkManager)
  domain/           гроші, дати, нормалізація мерчанта, парсери сповіщень, use-cases
  notifications/    NotificationListenerService, канали, нагадування (AlarmManager)
  ui/               Jetpack Compose: огляд, історія, операція, аналітика, плани, гаманці, категорії, банки, налаштування
docs/superpowers/specs/  дизайн-документ
```

Kotlin 2.0 · Jetpack Compose (Material 3) · Room · DataStore · WorkManager · Retrofit + kotlinx.serialization.
minSdk 26, targetSdk 35. Усі дані зберігаються лише на пристрої.
